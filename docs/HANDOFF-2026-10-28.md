## Release routine

- Work branch: `claude/laughing-shannon-gr58c4`.
- Each release goes: push the branch → wait until every GitHub workflow run on that commit succeeds → push the same commit to `main`. A push to `main` deploys Vercel and applies new Supabase migrations.
- Live: https://syllabi-study.vercel.app. `/api/version` returns the live commit.
- The release script lives in the session scratchpad and is lost when a session ends. Recreate it from this copy:

```bash
#!/usr/bin/env bash
# Push the branch, wait for EVERY GitHub workflow run on HEAD, and only if all pass push to main and wait for Vercel.
set -uo pipefail
cd /home/user/syllabi
B=claude/laughing-shannon-gr58c4
[ -z "$(git status --porcelain)" ] || { echo "UNCOMMITTED CHANGES"; exit 1; }
git diff --quiet origin/main -- public/sounds || { echo "SOUNDS CHANGED: not releasing"; exit 1; }
git push -q -u origin $B || exit 1
H=$(git rev-parse HEAD); echo "branch at $H"
api=https://api.github.com/repos/mrravimalhotra/syllabi/actions
runs() { curl -s "$api/runs?head_sha=$H&event=push&per_page=50" | python3 -c "
import sys,json
r=[x for x in json.load(sys.stdin).get('workflow_runs',[]) if x['head_branch']=='$B']
for x in r: print(x['id'], x['name'].replace(' ','_'), x['status'], x['conclusion'])"; }
until [ -n "$(runs)" ]; do sleep 10; done
sleep 30  # let every workflow for this push register
until ! runs | grep -qv " completed "; do sleep 30; done
runs | while read id name status concl; do
  echo "  $name: $concl"
  curl -s $api/runs/$id/jobs | python3 -c "import sys,json;[print('     ',j['name'],j['conclusion']) for j in json.load(sys.stdin)['jobs']]"
done
if runs | grep -qv " success$"; then echo "CHECKS FAILED: not releasing"; exit 1; fi
git push -q origin "$H:refs/heads/main" || exit 1
for i in $(seq 1 40); do v=$(curl -s https://syllabi-study.vercel.app/api/version); case "$v" in *$H*) echo "LIVE after $((i*15))s: $v"; exit 0;; esac; sleep 15; done
echo "pushed to main but not live after 10 minutes"; exit 1
```

Run it in the foreground (it takes 10–20 minutes). Don't `pkill` or `pgrep -f` it by name: that kills your own shell.
